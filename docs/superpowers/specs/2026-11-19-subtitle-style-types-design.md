# 字幕样式四分类（Title / Bilingual / Note / Unilingual）设计

日期：2026-11-19　规模：小改动（只涉及字幕批量校准的分类与样式头）

## 目的

让输出字幕的样式标签更规范：每种类型内部格式一致，以后想调字幕样式时可以按类型整体调整。

## 目标 / 不做 / 要避免

- **目标**：输出的每条 `Dialogue` 归入四种样式之一；规则确定、可预期；拿不准的在结果列表标出来交给人工。
- **不做**：不改播放器；不改各样式的字体、字号、边距数值（只改名、新增 Unilingual）；不同步内置初始数据 `src-tauri/resources/seed/subtitles`（发版时照旧处理）；不改更新日志。
- **要避免**：同一种样式里混入单行和两行字幕（那样按类型调边距会互相打架）；为了凑规则去臆改正文。

## 分类规则

判断只看中文段的**可见文字**（忽略 `{...}` 标签），按下面顺序命中即止：

| 顺序 | 条件 | 样式 |
|---|---|---|
| 1 | 有英文译文（中英双语行） | `Bilingual` |
| 2 | 整行就是一对 `《…》` | `Title` |
| 3 | 整行被一对 `(…)` 或 `[…]` 包裹 | `Note` |
| 4 | 其余单行 | `Unilingual` |

**"完整包裹"的定义**：开头的括号与结尾的括号是同一对。
- `(露西 电话(626) 584-5923)` 是（嵌套不影响）。
- `(枪声)(枪声)`、`《兄弟连》 《太平洋战争》` 不是（多段拼接）。
- `《XXX》后面还有字`、`前面有字《XXX》`、`[外语] 早上好` 不是。
- 外层是括号、里面有书名号（`(正在播放 《某歌》)`）按外层算 `Note`。

## 伴随的文字规整

- **`《` 前的空白**：所有行的中文段里，紧贴在 `《` 前面的空格（含全角）一律删除。
- **Title 行**：书名号内的 `:` 统一为 `：`，删除全部空格（含全角）。
- **Note 行**：中文括号统一改成英文括号——`（）→()`，`【】`、`［］→[]`，行内嵌套的同样转换。
- 非 Note 行里的中文括号保持现状（现有规则仍把中文段的 `()` 全角化为 `（）`）。*这是实现者的判断：需求只提到 Note 行。*

## 样式头

```
Style: Bilingual   = 原 Default 的参数（SimHei 32，MarginV 10）
Style: Unilingual  = 与 Note 相同的参数（SimHei 32，MarginV 40）
Style: Title       = 不变（SimHei 35，MarginV 30）
Style: Note        = 不变（SimHei 32，MarginV 40）
```

输出里不再有 `Default`。影响：约 31 万行普通单行字幕由 MarginV 10 变为 40（这是需求明确要求的"样式与 Note 一致"）。

> 实测（2026-11-19，`docs/subtitles` 全库 1328 个文件）：Bilingual 949,200 行、Unilingual 314,245 行、Note 9,329 行、Title 1,172 行；样式存疑(双语) 424、(多段) 6、(未闭合) 30。下文表格里的"库里约"是动手前的估计。

## 结果列表里的"样式存疑"

不自动改，只提示，由人工双击编辑：

| 标签 | 情形 | 归类 | 库里约 |
|---|---|---|---|
| `样式存疑(双语)` | 双语行的中文段被 `《》` 或括号完整包裹，如 `《小红帽》` + `Snow White?` | `Bilingual` | 400 行 |
| `样式存疑(多段)` | 单行由多段包裹拼成，如 `(枪声)(枪声)` | `Unilingual` | 20 行 |
| `样式存疑(未闭合)` | 单行以 `(`/`（` 开头却没有完整包裹，如 `（两天没换的衬衫`、`（贝克街） 221号B`；或以 `[`/`《` 开头但整行找不到对应的闭合符号 | `Unilingual` | 40 行 |

不提示的：`[外语] 早上好`、`看过《圣经》` 这类——按规则没有歧义，提示只会是上千条噪音。

已知代价：`样式存疑(双语)` 只有把英文删掉（变成单行）才会消失；认为它本来就该是双语的话，提示会一直在。

## 撤销的旧规则

2026-11-19 上午加的"出现 `[外语]` / `[某语种]` 就用 Note（位置不限）"与"必须完整包裹"冲突，整条撤销（`has_language_tag` 及其测试删除）。`[外语] 早上好` 单行归 `Unilingual`（外观与 Note 相同），双语归 `Bilingual`。

## 考虑过的做法

- **A 双语优先（采用）**：有英文就是 `Bilingual`，其余三种只含单行；双语且被完整包裹的约 400 行归 `Bilingual` 并标"样式存疑"。每种类型行数固定，按类型调样式互不干扰。用户于 2026-11-19 选定。
- **B 包裹优先**：中文被完整包裹就归 `Title`/`Note`，不管有无英文。语义更直观，但 `Title`/`Note` 会同时含单行和两行，调边距时一起动。未采用。
- **C 双语优先但不提示**：最安静，但不符合"有异议的标出来人工判断"的要求。未采用。
