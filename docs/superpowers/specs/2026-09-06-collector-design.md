# Collector — 本地影音漫游素材管理与查看器 · 设计文档

- 日期：2026-09-06
- 状态：设计已确认，待用户复审
- 技术栈：Tauri（Rust 后端 + WebView 前端）

## 1. 目标与范围

Collector 是一个跨平台（macOS + Windows）桌面应用，用于**管理、标准化并一站式查看/运行**三类本地素材：

- **视频**（MKV 格式，分类：电影 / 动漫 / 电视剧）
- **漫画**（Zip 压缩包，内含 JPG 图片）
- **游戏**（绿色版 / 免安装）

两条能力线：

1. **原始素材标准化**（独立批处理工具台）——把杂乱的字幕、漫画整理成统一的标准格式。
2. **一站式查看 / 运行**——内嵌播放器、漫画阅读器、游戏启动器。

要求：架构扩展性强、UI 采用「深邃玻璃拟态」科技感风格并带动画特效、无网络依赖。

## 2. 核心技术决策（已确认）

| 决策点 | 结论 | 理由 |
|---|---|---|
| MKV 播放 | **内嵌 libmpv 内核**（Rust FFI 控制） | WebView 自带 `<video>` 不支持 MKV 容器及 H.265 等编码；mpv 提供硬件解码、最全字幕支持，是工业级方案 |
| 视频层合成 | **mpv 渲染到独立子窗口 + Tauri 半透明控制条浮层** | 字幕由 mpv 的 libass 渲染，位置精准；集成风险可控；炫酷动画放在 UI 层 |
| 元数据来源 | **纯本地**（目录结构 + 侧载文件） | 无网络依赖、隐私好、可靠 |
| 索引 | **本地 SQLite 缓存** | 启动快，不必每次全盘扫描；存扫描结果与用户状态 |
| 字幕标准化 | **移植 demo 核心逻辑，脏数据映射表可配置** | 保留双语合并 / 样式重建 / 标点全角化，把针对特定片源的硬编码字符映射改为可配置规则表 |
| 标准化触发 | **独立批处理专区** | 显式选文件夹 → 跑处理 → 看质检报告 → 确认，与浏览查看分离 |
| 字幕加载 | **只用外挂 `.ass`** | 与 demo 工作流一致，位置由 ASS 样式 `MarginV`/`Alignment` 控制 |
| 漫画阅读 | **翻页为主（单/双页 + 翻书动画），可切长条滚动** | 底层按需流式解压 + 预取缓存，避免整包解压爆内存 |
| 游戏启动识别 | **靠侧载配置 `game.json` 指定** | 最可靠，避免误判 unins/setup/redist |
| 视觉风格 | **深邃玻璃拟态**（蓝黑渐变 + 毛玻璃卡片 + 柔和高光） | 精致克制，与视频浮层控制条天然契合 |
| 主导航 | **左侧常驻边栏** | 功能区常驻可见，切换快，桌面主流 |

## 3. 整体架构

三层结构，前后端经 Tauri IPC（commands + events）通信：

```
前端 WebView（玻璃拟态 UI + 动画）
  视频库 / 播放控制条 · 漫画阅读器 · 游戏库 · 标准化工具台 · 设置
        ↕  Tauri commands / events (IPC)  ↕
后端 Rust（Tauri core），模块隔离：
  library    扫描器 + SQLite 索引（分类/封面/进度/最近启动）
  player     libmpv FFI（子窗口渲染 + 外挂 .ass 加载 + 播放控制）
  comic      zip 流式解压 + 预取缓存
  launcher   进程启动（按当前平台过滤 .exe/.app）
  normalize  字幕清洗引擎 + 漫画重命名/JPG统一/打zip/质检
        ↕
外部依赖 / 文件系统：
  libmpv 动态库（随包分发）
  视频根目录 /分类/剧名/*.mkv + *.ass + poster.jpg + info.txt
  漫画根目录 /分类/*.zip（+ 同名 .txt 可选）
  游戏根目录 /游戏名/ + game.json + cover.jpg + info.txt
```

**模块隔离原则**：每个后端模块单一职责、通过明确的 command 接口对前端暴露能力，可独立测试。`normalize`（工具线）与 `library`/`player`/`comic`/`launcher`（查看线）互不依赖。

## 4. 数据模型与侧载约定

### 4.1 目录与侧载约定（默认，不污染原始素材外的自有配置）

- **视频**：`<视频根>/<分类>/<剧名>/`
  - 分类 = 一级目录名，取值 `电影` | `动漫` | `电视剧`
  - `*.mkv` 视频文件；同名 `*.ass` 外挂字幕
  - `poster.jpg` 封面（缺失则用抽帧占位/默认图）
  - `info.txt` 简介（可选）
- **漫画**：`<漫画根>/<分类>/<漫画名>.zip`
  - 封面 = zip 内第一张图（按文件名排序）
  - 同名 `.txt` 简介（可选）
- **游戏**：`<游戏根>/<游戏名>/`
  - `game.json`：指定 `exec_win`（Windows 启动相对路径）、`exec_mac`（macOS 启动相对路径，如 `.app`）、`name`（显示名）、`description`（简介，可选，缺失时读 `info.txt`）、`fullscreen`（可选，启动时是否传全屏参数）
  - `cover.jpg` 缩略图

### 4.2 SQLite 索引（应用私有，存于用户数据目录）

- `media_item`：id、类型（video/comic/game）、分类、标题、路径、封面路径、简介、平台可用性、扫描时间
- `watch_state`：视频观看进度（秒）、漫画阅读页码、最近打开时间
- `game_state`：最近启动时间、启动次数
- 索引作为缓存：扫描根目录时增量更新，支持「重新扫描」。

### 4.3 跨平台游戏处理

绿色版游戏通常平台专属（Windows `.exe` vs macOS `.app`）。库视图按当前平台过滤：
- 当前平台有可用启动路径 → 正常显示，可启动
- 仅有另一平台启动路径 → 显示但标注「本平台不可用」，禁用启动

## 5. 功能模块详述

### 5.1 视频（library + player）

- 视频库：按分类（电影/动漫/电视剧）标签切换，海报网格展示，显示观看进度。
- 播放：Rust 通过 libmpv FFI 在独立子窗口渲染视频；Tauri 前端渲染半透明玻璃控制条浮层。
- 字幕：加载同名/同目录外挂 `.ass`（标准化产物），libass 渲染，垂直位置由样式 `MarginV`/`Alignment` 决定（落在视频下方）。
- 控制：播放/暂停、快进/快退（seek）、音量、进度条、全屏切换、字幕开关。
- 进度：退出时写回 `watch_state`，下次续播。

### 5.2 漫画（comic）

- 阅读器：按需流式解压（只解当前页 + 预取前后 N 页），LRU 缓存，避免整包解压。
- 默认翻页模式（单页/双页自适应宽度，带翻书动画），可切换长条垂直滚动。
- 记忆阅读页码（`watch_state`），支持跳页、缩放。

### 5.3 游戏（launcher）

- 游戏库：缩略图（`cover.jpg`）+ 名称 + 简介卡片网格。
- 双击启动：Rust 按当前平台从 `game.json` 取启动路径，spawn 进程；可选传全屏参数。应用只负责启动进程，不接管游戏窗口。
- 记录最近启动时间/次数。

### 5.4 标准化工具台（normalize）

独立专区，与浏览查看分离。工作流：**选文件夹 → 预览/配置 → 执行 → 质检报告 → 确认**。

**字幕标准化引擎**（移植 `SubtitlesFormat` 核心逻辑）：
- 按时间戳 key 合并中英双语行
- 用固定分隔符 `\N{\fnArial\fs30}` 拼接中英
- 重建统一样式头（`[Script Info]` / `[V4+ Styles]` / `[Events]`，Default/Title/Note 样式）
- 中文标点全角化、英文标点规整
- **可配置的字符映射表**（原 demo 中针对特定片源脏数据的硬编码 `.replace` 改为规则配置文件）
- 质检扫描（移植 `SubtitlesSearch` 逻辑）：标点异常、双语结构缺失、时间轴逆序、可疑字符等，输出报告供人工确认

**漫画标准化**（移植 `ComicRename` + `ComicAdjust` 核心逻辑）：
- 目录内图片按序重命名为 `<名字>_<序号>.jpg`（序号补零对齐）
- 统一转为标准 JPG 格式
- 清理无关文件（如 `Thumbs.db`）
- 打包为 zip

### 5.5 设置

- 配置三个素材根目录
- 重新扫描 / 清理索引
- 标准化规则配置（字符映射表、字幕样式参数、漫画命名模板）
- 主题细节（若开放）

## 6. UI / 视觉规范

- 风格：深邃玻璃拟态。底色蓝黑渐变（约 `#0d1220 → #131a2e`），卡片半透明 + `backdrop-filter` 毛玻璃 + 细边框高光，强调色蓝紫（约 `#5b8cff`）。
- 导航：左侧常驻边栏（视频/漫画/游戏在上，标准化/设置沉底）。
- 动画：启动页、菜单切换、卡片 hover、控制条淡入淡出、漫画翻页；视频播放区保持专业干净（动画在 UI 浮层，不混入视频像素）。
- 深色为主（玻璃拟态天然适配深色）。

## 7. 打包与分发

- macOS 与 Windows 各打一份，随包分发对应的 libmpv 动态库。
- 无网络依赖，纯本地运行。

## 8. 明确不做（YAGNI）

- 不联网刮削元数据（TMDB/豆瓣等）
- 不做 MKV 内嵌字幕轨加载（只用外挂 `.ass`）
- 不接管游戏窗口的全屏/窗口切换（交给游戏自身，仅可选传参）
- 不做 mpv 纹理级合成特效
- 不在此版本做移动端 / Web 端

## 9. 分阶段实现建议（供后续实现计划参考）

实现虽在一份设计内，但建议分阶段落地：

1. 骨架：Tauri 工程、左侧边栏导航、玻璃拟态基础组件、SQLite + 扫描器、设置页配置根目录
2. 漫画阅读器（相对独立、风险低，先跑通查看闭环）
3. 视频播放器（libmpv FFI 集成，最高技术风险，重点攻关）
4. 游戏启动器
5. 标准化工具台（字幕引擎 + 漫画打包 + 质检报告）
6. 打磨：动画特效、跨平台打包验证
