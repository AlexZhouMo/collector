# 增强优化建议：多标点分词探索 + 最多 2 个候选

## 目标

增强海报「更新海报」的优化建议：对未命中视频，用多种标点切分 title + 累加组合生成候选名，逐个探索 TMDB，年份校验后**最多返回 2 个候选建议名**，表格里并列展示（绿色药丸）。提升那 27 条（多标点/口号前缀的动漫剧场版、副标题续集片）的建议命中率。

## 问题

当前 suggest 只试两个候选（副标题冒号前主名、去尾数字），对多标点 title 几乎无效。实测 27 条未命中的 title 模式：
- 感叹号前缀口号：`热血热斗！孙悟空与悟饭`、`呼风唤雨！3分钟百变大进击`
- 点号分隔多段：`拉欧传.激斗之章`、`冥王龙与冰空的花束.雪米`、`零.健四郎传`
- 中点分隔：`热战·烈战·超激战`
- 冒号副标题：`异形前传：普罗米修斯`、`死亡飞车3：地狱烈焰`
- 无标点含系列数字：`铁血战士2010`、`霹雳娇娃2`

## 决策汇总

| 项 | 决策 |
|----|------|
| 分词策略 | 多标点切分 + 前缀累加组合 + 去首段后缀组合 |
| 建议数量 | 最多 2 个候选，表格并列绿色药丸 |
| 选取规则 | 年份校验(±1)通过的命中，按候选词段长度降序、TMDB 标题去重，取前 2 |
| 误配防线 | 年份校验 + 取较长词段；文案仍为「建议」，用户手动确认 |

## 改动方案

### 1. `poster/parse.rs` 新增纯函数
```rust
/// 从片名生成 TMDB 搜索候选集，供优化建议探索。
/// 按多标点（！!。.·：: 及空格）切分词段，生成：完整名、各单词段、
/// 前缀累加组合、去首段的后缀组合；去重去空，按长度降序（越长越可能是完整片名）。
pub fn suggest_candidates(name: &str) -> Vec<String>
```
实现：
- 用字符集 `['！','!','。','.','·','：',':',' ','　']` 切分为 segs（去空）。
- 候选：完整 name；每个 seg；前缀累加拼接 seg[0..k]（k=1..n，直接相连无分隔）；去首段的 seg[1..]（拼接）。
- HashSet 去重，过滤空串和过短（长度<2 的忽略，避免单字噪声）。
- 按字符长度降序排序返回。

### 2. `poster/mod.rs`
- `FailedItem`：`suggest_name: Option<String>` 改为 `suggest_names: Vec<String>`。
- `fetch_posters` 的 suggest 闭包签名：`FnMut(&MediaQuery, &str) -> (Vec<String>, String)`；失败分支填 `suggest_names: names.clone()`。
- 测试 3 处 suggest 闭包返回 `(vec![], "...".into())`。

### 3. `lib.rs` suggest 闭包
- 剧集季无海报分支不变（返回 `(vec![], "回退整剧" note)`）。
- 否则：`let cands = poster::parse::suggest_candidates(&q.name);`
- 遍历候选（动漫 movie/tv 双试，其余按 kind），搜 `search_detailed`，年份校验(±1)通过的收集为 `(候选长度, TMDB标题)`。
- 按候选长度降序、TMDB 标题去重，取前 2 个标题 → `suggest_names`。
- 有候选：note = "译名/名称与 TMDB 不符，改为以下名可命中"；无：note = 现有通用提示，`suggest_names = vec![]`。
- 限流：候选数 ≤ ~8，仅未命中项执行，串行 + 现有节奏。

### 4. `ipc.ts`
`FailedItem` 接口：`suggest_name: string | null` → `suggest_names: string[]`。

### 5. `NormalizeView.ts` renderPosterTable
优化建议列：`suggest_names.length` > 0 时渲染说明 + 并列绿色药丸（每个 name 一个 `.pt-pill`）；否则橙色提示。title 属性拼接完整文案。仍单行省略。

### 6. `theme.css`
`.pt-pill` 间距（多个并列时留 gap）；无需大改。

## 测试策略

- `suggest_candidates` 单测：
  - `热血热斗！孙悟空与悟饭` → 候选含「孙悟空与悟饭」「热血热斗」及完整名。
  - `拉欧传.激斗之章` → 含「拉欧传」「激斗之章」「拉欧传激斗之章」。
  - `热战·烈战·超激战` → 含各段。
  - 去重、过滤单字、按长度降序。
- `poster::tests`：suggest 闭包返回 `(vec![], ...)`，断言 failed 项 suggest_names 字段存在。
- 真机：27 条重跑「更新海报」，看命中数提升、双候选并列展示。

## 明确不做（YAGNI）

- 不做 3+ 个候选（最多 2）。
- 不自动改库（仍用户手动）。
- 不引入分词库（简单标点切分足够）。
- 不改抓取主流程（仅建议探测）。

## 风险

- 激进分词可能切出系列泛名命中错片——年份校验 + 取较长词段两道防线降低误配；同年多部仍可能不准，文案为「建议」。
- 每条候选多发请求，仅 27 条未命中项，可接受。
