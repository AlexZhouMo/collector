## 来源与网络情况

- **TMDB**（应用内置的海报源）：API 域名 `api.themoviedb.org` 被墙，本机无法访问 —— 这正是这 29 部当初在应用里"未命中"的根因。
- **豆瓣**：中文片名精准、海报为 1080px 高清竖版，是最佳来源；但对本机 IP **强限流/封禁**，只有零星请求能穿透，故命中率低。**日后 IP 解封可重新抓取，届时可补齐缺失的 11 部真海报。**
- **维基百科**：好莱坞片有真实海报（尺寸偏小）；日本动画剧场版条目普遍无内嵌海报。
